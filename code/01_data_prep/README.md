# Stage 1 — Input data and ESM-1v embeddings

## ESM-1v embeddings are not re-implemented here

ACE2-binding measurements for the combinatorial RBD mutant library, and the ESM-1v
representation of each mutant sequence, were taken from the published work of
Wang et al., and their code is **not duplicated in this repository**. Use theirs:

> Wang, D., Huot, M., Mohanty, V., and Shakhnovich, E.I. (2024).
> Biophysical principles predict fitness of SARS-CoV-2 variants.
> *Proc. Natl. Acad. Sci. U.S.A.* **121**. https://doi.org/10.1073/pnas.2314518121
>
> Code and data: **https://github.com/Dianzhuo-Wang/COVID19-Biophysical-Model**

Each 201-residue RBD sequence (spike positions 331–531) is represented by the
final-layer ESM-1v (`esm1v_t33_650M_UR90S_1`) hidden states, mean-pooled across residues
into a single **1 × 1,280** vector. That vector is the input to every model in
[`../02_dnn_ace2/`](../02_dnn_ace2).

The underlying deep mutational scanning measurements were originally generated by
Moulana et al. (2022), *Nat. Commun.* https://doi.org/10.1038/s41467-022-34506-z.

## What this folder does contain

Scripts that prepare the subset of that data analysed in the present study:

| Script | Role |
|---|---|
| `raw_data_15mut.R` | Reads the full 15-locus combinatorial dataset (32,565 genotypes) |
| `df_5_mut.R` | Restricts it to variants carrying 1–5 mutations, following the model selection of Moulana et al., leaving **4,923 measurements** |
